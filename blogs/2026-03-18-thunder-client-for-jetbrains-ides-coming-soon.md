Thunder Client is Coming to JetBrains IDEs We’re excited to announce that Thunder Client , the lightweight REST API client, is expanding beyond VS Code and coming to JetBrains IDEs. Launch Update Thunder Client for JetBrains is now in its final testing phase. Soon, developers using IntelliJ IDEA, WebStorm, PyCharm, and other JetBrains IDEs will be able to test APIs directly within their preferred IDE without switching tools.
